# History

The files in this folder describe earlier contracts and earlier states of the code: `dmw-x8cx.testnet` (the first
testnet contract, Nov 7 to 10 2026) and `dmw-979268.testnet` (contract v1, Nov 11 to 12 2026), both replaced by the
live contract. They are kept as the record of how the project got here: test runs, transcripts, dry runs and audits
made against those contracts, and notes on earlier video cuts. Findings they list as open were fixed later or are
tracked in the current documents. For the deployed code and its runs, read [`docs/LIVE_CONTRACT.md`](../LIVE_CONTRACT.md);
for the security record, [`docs/SECURITY_FIXES_V2.md`](../SECURITY_FIXES_V2.md) and the reviews it links.
